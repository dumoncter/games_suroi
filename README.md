# Suroi Team Server

## Обзор

Этот репозиторий содержит сервер для командных боев Suroi. Он использует общий код из основного репозитория `/var/www/neonpsh.ru/games_portal/suroi`.

## Архитектура

```
server_team/          # Этот репозиторий (ветка server-team)
├── server/           # Серверный код (копия из основного репозитория)
├── common/           # Общие модули (для компиляции)
├── scripts/          # Скрипты запуска
├── railway.toml      # Конфигурация Railway
├── Dockerfile        # Docker образ
├── nginx.conf        # NGINX конфигурация
└── git_push_server-team.sh  # Скрипт деплоя с автоматической синхронизацией
```

## Развертывание

### Локально
```bash
./start-team-server.sh
```

### Production (Railway)
```bash
./git_push_server-team.sh "Ваше сообщение коммита"
```

**Примечание**: Скрипт автоматически синхронизирует код с основным репозиторием перед деплоем.

## Конфигурация

- **Порт**: 8083
- **Режим**: Team (дуо/сквады с ротацией)
- **Railway URL**: `https://suroi-team.neonpsh.games`

## Синхронизация с основным репозиторием

**Автоматическая синхронизация**: Скрипт `./git_push_server-team.sh` автоматически синхронизирует код с основным репозиторием перед каждым деплоем.

**Ручная синхронизация** (если нужно):
```bash
# Из основного репозитория
./sync-servers.sh
```
