# Suroi Solo Server

## Обзор

Этот репозиторий содержит сервер для одиночных боев Suroi. Он использует общий код из основного репозитория `/var/www/neonpsh.ru/games_portal/suroi`.

## Архитектура

```
server_solo/          # Этот репозиторий (ветка server-solo)
├── server/           # Серверный код (копия из основного репозитория)
├── common/           # Общие модули (для компиляции)
├── scripts/          # Скрипты запуска
├── railway.toml      # Конфигурация Railway
├── Dockerfile        # Docker образ
├── nginx.conf        # NGINX конфигурация
└── git_push_solo.sh  # Скрипт деплоя с автоматической синхронизацией
```

## Развертывание

### Локально
```bash
./start-solo-server.sh
```

### Production (Railway)
```bash
./git_push_solo.sh "Ваше сообщение коммита"
```

**Примечание**: Скрипт автоматически синхронизирует код с основным репозиторием перед деплоем.

## Конфигурация

- **Порт**: 8082
- **Режим**: Solo (одиночные бои)
- **Railway URL**: `https://suroi-solo.neonpsh.games`

## Синхронизация с основным репозиторием

**Автоматическая синхронизация**: Скрипт `./git_push_solo.sh` автоматически синхронизирует код с основным репозиторием перед каждым деплоем.

**Ручная синхронизация** (если нужно):
```bash
# Из основного репозитория
./sync-servers.sh
```
